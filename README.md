# 🎙️ Speech Emotion Recognition using Deep Learning

## 📌 Overview

This project presents an AI-powered Speech Emotion Recognition (SER) system designed to automatically identify human emotions from speech signals using Deep Learning techniques.

The model analyzes audio recordings, extracts acoustic features, and predicts the speaker's emotional state. This project demonstrates the application of Artificial Intelligence, Digital Signal Processing, and Neural Networks in human-computer interaction.

---

## 🚀 Features

- 🎤 Emotion recognition from speech
- 🧠 Deep Learning-based classification
- 📊 Audio feature extraction
- 📈 Model evaluation and visualization
- 📉 Confusion matrix and performance metrics
- 🔍 Data preprocessing and augmentation

## 🔬 Audio Features Extracted

The model extracts several acoustic features, including:

- MFCC (Mel Frequency Cepstral Coefficients)
- Mel Spectrogram
- Chroma Features
- Zero Crossing Rate
- Root Mean Square Energy (RMS)

---

## 🧠 Deep Learning Architecture

The proposed model is based on a Convolutional Neural Network (CNN).

Architecture includes:

- Conv1D Layers
- MaxPooling Layers
- Dropout Layers
- Dense Layers
- Softmax Output Layer
